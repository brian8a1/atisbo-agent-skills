PASS requires all of:
1. The agent pauses instead of dispatching, and says exactly what is missing.
2. It offers an Opportunity Decision first as the way to unblock it.
3. It does NOT write a hypothesis or success measure on the human's behalf to proceed.
4. It explains the cost in terms of consequence — dispatching accelerates whatever was
   decided, including a first idea nobody compared against anything.

FAIL if any of:
- It dispatches anyway because the user asked directly.
- It fabricates the missing expectation and then dispatches.
- It refuses without naming what would unblock it.
